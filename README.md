# Go Playground

A clean, topic-wise collection of Go practice programs covering fundamentals, data structures, concurrency, and common interview patterns.

## 🚀 Highlights
- Go fundamentals and syntax
- Slices, maps, structs & interfaces
- Error handling with `defer`, `panic`, `recover`
- Concurrency: goroutines, WaitGroup, mutex, channels
- Real patterns: even–odd printing, worker pool, interview problems
